AL-Router

Условия использования

Обновлено: 3 ноября 2026

1. Что это

AL-Router — личный технический шлюз, который принимает один ключ доступа и перенаправляет запросы к API моделей, которые вы подключили сами. Сервис не продаёт доступ к моделям и не предоставляет собственные API-ключи.

2. Ваши ключи и правила провайдеров

Вы добавляете собственные API-ключи сторонних сервисов (NVIDIA Build, DeepSeek, OpenCode и других). Используя их через шлюз, вы обязаны соблюдать их условия: бесплатные ключи обычно разрешены только для личного использования, а передача доступа третьим лицам, перепродажа и автоматизация сверх лимитов запрещены. Ответственность за нарушение этих правил лежит на вас.

3. Аккаунт

  • Не передавайте Master Key третьим лицам — это фактически пароль от вашего доступа.
  • Один аккаунт — один владелец. Регистрация чужих аккаунтов и массовое создание — запрещены.
  • Администратор может ограничить или закрыть регистрацию и удалить аккаунт при злоупотреблении.

4. Ограничения и лимиты

Действуют технические лимиты частоты запросов и размера тела запроса. Их можно менять без предупреждения, чтобы сервис оставался доступным.

5. Гарантии

Сервис предоставляется «как есть», без гарантий доступности, сохранности данных и пригодности для конкретных задач. Возможны перезапуски, потеря данных на бесплатном хостинге и изменения API провайдеров. Не используйте сервис для задач, где ошибка приводит к ущербу.

6. Запрещено

  • Обходить лимиты и правила провайдеров моделей.
  • Использовать сервис для незаконного контента или атак на инфраструктуру.
  • Перепродавать доступ к сервису или выдавать его за продукт NVIDIA, Google, OpenAI, OpenRouter.
  • Пытаться получить доступ к чужим аккаунтам и ключам.

7. Ответственность

Администратор не отвечает за блокировки ваших ключей провайдерами, за содержание ответов моделей и за последствия использования сгенерированных материалов. Претензии по работе моделей предъявляются их провайдерам.

8. Изменения

Условия могут меняться. Актуальная версия всегда на этой странице. Продолжая пользоваться сервисом, вы принимаете новую редакцию.
