AL-Router

Политика конфиденциальности

Обновлено: 3 ноября 2026

1. Кто обрабатывает данные

AL-Router — частный технический проект. Оператор сервиса указан в разделе «Контакты» внизу страницы. Сервис не связан с NVIDIA, Google, OpenAI или OpenRouter и не действует от их имени.

2. Какие данные хранятся

  • Email — идентификатор аккаунта.
  • Хеш пароля (bcrypt) — если вход по email. Сам пароль не хранится.
  • Master Key — ключ доступа к API сервиса.
  • API-ключи провайдеров, которые вы добавили сами.
  • Технические логи: время запроса, путь, статус, IP-адрес.

3. Зачем

Только для работы сервиса: вход в аккаунт, проксирование запросов к выбранному вами провайдеру, отображение статистики. Данные не продаются и не передаются третьим лицам, кроме случаев, прямо необходимых для работы сервиса.

4. Кому передаются данные

  • Провайдеру модели — запрос и ваш API-ключ этого провайдера, иначе запрос не выполнить.
  • Google — при входе через Google передаётся OAuth-запрос; сервис получает email и имя профиля.
  • Хостинг и база данных — Render и Neon (Postgres) хранят данные на своих серверах.

5. Cookies и локальное хранилище

Используется один технический cookie oauth_state (защита от CSRF при входе через Google, живёт 10 минут) и localStorage для токена сессии. Аналитики и рекламных трекеров нет.

6. Сроки и удаление

Данные хранятся, пока существует аккаунт. Удалить аккаунт и все связанные записи можно по запросу на контактный email — удаление выполняется вручную в течение 30 дней. Сессии с истёкшим сроком удаляются автоматически.

7. Безопасность

Соединение с сервисом шифруется (HTTPS), пароли хранятся в виде bcrypt-хешей, доступ к API — только по Master Key. При этом сервис работает на бесплатном хостинге и не является системой с повышенными требованиями к защите: не используйте его для конфиденциальных данных.

8. Ваши права

Вы можете запросить доступ к своим данным, их исправление или удаление, а также отозвать согласие, удалив аккаунт. Для этого напишите на контактный email.
